# 🌍 Dream Travel - Explore the World

This is a simple **HTML project** named **Dream Travel**, created to showcase basic web design concepts such as text formatting, images, hyperlinks, lists, tables, and contact details.

---

##  Project Overview

The **Dream Travel** website is designed to give users a glimpse of exciting travel destinations and activities. It demonstrates how HTML can be used to structure content and present information in a clean and organized way.

---

##  Features Implemented

1. **Header Section**

   * Project title and tagline.

2. **Introduction Section**

   * Paragraphs with text formatting (`bold`, `italic`, `underline`, `strike`).

3. **Images Section**

   * Popular travel destination (Taj Mahal).
   * Exciting travel activity (Paragliding).

4. **Hyperlinks Section**

   * Internal and external navigation links.

5. **Lists Section**

   * Ordered list (Top 5 destinations).
   * Unordered list (Travel essentials).
   * Definition list (Travel terms).

6. **Table Section**

   * Travel packages with destination, price, and duration.

7. **Contact Section**

   * Email, phone, and office address.

8. **Footer**

   * Copyright and designer name.
